MCP · Model Context Protocol · Apache-2.0

让 AI Agent 真正操作 DAW

daw-mcp-server 把 FL Studio / REAPER / DAWproject 的自动化接口封装成 11 个 MCP tools：读工程、套用混音 patch、渲染、测量 LUFS/频谱/立体声、闭环验证——给音乐 AI 的训练与推理用。

GitHub 仓库 下载 Release DAW 接口清单

11 个 Tool

Tool作用
project_read读 .rpp / .dawproject：轨道、音量/声像、send、marker、tempo
patch_validate / patch_apply校验/套用混音 IR patch（音轨、EQ、压缩、send、marker）
render真实 DAW 命令渲染（reaper -renderproject）或 mock 渲染
analyze / compareWAV：peak/RMS/LUFS/LRA/频谱质心/频带/立体声宽度/相关度
verify_patch闭环：apply → render baseline+patched → analyze → 按 intent 打分
bridge_calllive DAW 桥：get_state / set_track / set_eq / set_comp / add_marker
telemetry_append操作/验证结果写 JSONL，训练数据回流

30 秒上手

git clone https://github.com/ShokouP/daw-mcp-server
cd daw-mcp-server
python -m pip install -r requirements.txt
python tests/test_smoke.py      # 无需安装 DAW
python examples/training_loop.py

训练/推理闭环

模型输出 IR patch
  → patch_validate → patch_apply → render → analyze
  → verify_patch（打分） → bridge_call（应用到 live DAW）
  → telemetry_append（数据回流）
